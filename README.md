# Dissertation

MSc dissertation project: compression (structured pruning, INT8 quantisation) and
quality-filtering effects on ArcFace face-recognition models, evaluated on LFW.

## Repo layout

```
Code/                   Pipeline scripts, results, and (locally generated) weights/data
  baseline_pipeline.py  Detect -> align -> ArcFace embed -> cosine similarity -> LFW 10-fold eval
  structured_prune*.py  Structured channel pruning (ResNet-50 / MobileFaceNet variants)
  quantize_int8*.py     Post-training static INT8 quantisation (ResNet-50 / MobileFaceNet)
  qfilter_detect_and_score.py  FaceQNet-based quality scoring of LFW images (RQ3)
  run_qfilter_eval.py   Runs the quality-filtering sweep across all model variants
  compare_results.py    Aggregates results/*.json into summary tables
  results/              Output metrics (JSON) — committed
  data/                 Small derived data (quality scores, failure logs) — committed
  weights_variants/     Generated/downloaded model weights — NOT committed (see below)
  data/lfw*, lfw.tgz    Raw LFW dataset — NOT committed (see below)
Data/                   LFW metadata CSVs (people/pairs lists) — committed
  lfw-deepfunneled/     Raw LFW face images — NOT committed (see below)
weights/                Baseline ArcFace ResNet-50 ONNX — NOT committed (see below)
random files/           Dissertation drafts, marking criteria, format guide — committed
```

## Excluded files: setup guide

The following are excluded via `.gitignore` because they're large binaries or a
public dataset that's easy to re-download/regenerate. Recreate them locally as follows.

### 1. Environment

```bash
pip install facenet-pytorch insightface onnxruntime opencv-python tqdm scikit-learn numpy tensorflow
```

### 2. InsightFace pretrained models (ArcFace backbones)

The scripts load pretrained weights from the InsightFace model zoo, cached under
`~/.insightface/models/`. Easiest way to fetch them is via the `insightface` package,
which auto-downloads on first use:

```python
import insightface
insightface.model_zoo.get_model("buffalo_l")  # ResNet-50 backbone -> w600k_r50.onnx
insightface.model_zoo.get_model("buffalo_s")  # MobileFaceNet backbone -> w600k_mbf.onnx
```

This populates:
```
~/.insightface/models/buffalo_l/w600k_r50.onnx
~/.insightface/models/buffalo_l/det_10g.onnx   (SCRFD face detector)
~/.insightface/models/buffalo_s/w600k_mbf.onnx
```

For `weights/arcface_r50.onnx` (used directly by `baseline_pipeline.py`'s docstring
reference), copy `buffalo_l/w600k_r50.onnx` to `weights/arcface_r50.onnx`, or download
manually from the [InsightFace model zoo](https://github.com/deepinsight/insightface/tree/master/model_zoo)
(`buffalo_l`, ResNet-50, ArcFace, MS1MV3).

### 3. LFW dataset

```bash
# Raw images + pairs list
curl -O http://vis-www.cs.umass.edu/lfw/lfw.tgz
curl -O http://vis-www.cs.umass.edu/lfw/pairs.txt
tar -xzf lfw.tgz -C Code/data/          # -> Code/data/lfw/
mv lfw.tgz Code/data/
mv pairs.txt Code/data/

# Attributes file
curl -O https://www.cs.columbia.edu/CAVE/databases/pubfig/download/lfw_attributes.txt
mv lfw_attributes.txt Code/data/

# Deep-funneled variant (used for Data/*.csv protocol)
curl -O http://vis-www.cs.umass.edu/lfw/lfw-deepfunneled.tgz
tar -xzf lfw-deepfunneled.tgz -C Data/   # -> Data/lfw-deepfunneled/
```

The `Data/*.csv` files (people/pairs lists) are already committed — only the images
themselves need downloading.

### 4. FaceQNet weights (RQ3 quality filtering)

```bash
mkdir -p Code/weights_variants/faceqnet
curl -L -o Code/weights_variants/faceqnet/FaceQnet_v1.h5 \
  https://github.com/uam-biometrics/FaceQnet/releases/download/v1.0/FaceQnet_v1.h5
```

### 5. Generate compressed model variants

Once the base InsightFace weights are in place, regenerate the pruned/quantised
variants used by the evaluation scripts:

```bash
cd Code
python structured_prune.py       # -> weights_variants/w600k_r50_pruned.onnx
python structured_prune_mbf.py   # -> weights_variants/w600k_mbf_pruned.onnx
python quantize_int8.py          # -> weights_variants/w600k_r50_int8.onnx (+ opset13 fp32 copy)
python quantize_int8_mbf.py      # -> weights_variants/w600k_mbf_int8.onnx (+ opset13 fp32 copy)
```

### 6. Quality-filter cache

`Code/weights_variants/qfilter_cache/face112_stack.npy` (a cached stack of
ArcFace-ready 112x112 face crops) is regenerated by:

```bash
cd Code
python qfilter_detect_and_score.py
```

This also reproduces `Code/data/lfw_quality_scores.json` and
`Code/data/qfilter_detection_failures.json`, which are already committed.

### 7. Run the evaluation

```bash
cd Code
python baseline_pipeline.py      # FP32 ResNet-50 baseline
python run_variant.py            # other single-variant runs
python run_qfilter_eval.py       # full quality-filtering sweep -> results/*.json
python compare_results.py        # summarise results/*.json into tables
```
